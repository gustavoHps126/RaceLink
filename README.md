# Racelink

## Descrição do Projeto
O Racelink é um aplicativo focado em atuar como um planejador de jornada esportiva. Ele une a estruturação do calendário de treinos à logística colaborativa, sugerindo eventos preparatórios e disponibilizando um mural de anúncios para que atletas inscritos em uma mesma prova ofereçam ou busquem divisão de custos de viagem e hospedagem.

## Problema Abordado
Os altos custos logísticos (deslocamento e hospedagem) para participação em competições amadoras fora da cidade de origem e a falta de engajamento competitivo nos meses de preparação que antecedem uma prova principal.

## Objetivos
- Disponibilizar um mural de anúncios logísticos para atletas inscritos no mesmo evento.
- Promover o engajamento através de um calendário preditivo que sugere provas menores de preparação.
- Criar um ranking gamificado importando resultados preparatórios para estimular a competição pré-prova.
